# Kancelaria Radcy Prawnego

Responsywna strona wizytówkowa kancelarii radcy prawnego, przygotowana jako lekka strona statyczna bez procesu budowania i zewnętrznych zależności JavaScript.

## Uruchomienie lokalne

Otwórz plik `index.html` w przeglądarce albo uruchom dowolny prosty serwer HTTP w katalogu projektu.

## Personalizacja

Przed publikacją należy podmienić przykładowe dane kontaktowe w `index.html`:

- nazwę kancelarii oraz dane radcy prawnego,
- numer telefonu i adres e-mail,
- adres kancelarii i godziny pracy,
- zakres specjalizacji,
- treść polityki prywatności.

## Technologie

- HTML5
- CSS3
- JavaScript bez frameworka
